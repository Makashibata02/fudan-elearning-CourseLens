# 隐私说明

CourseLens 是非官方的本地浏览器扩展。没有接收用户作业的服务端、广告或遥测。

- 仅在复旦 eLearning 识别附件链接，使用同一浏览器的已有登录状态读取用户有权访问的附件；不读取或保存账号密码，没有 cookies API 权限。
- PDF、DOCX、PPT / PPTX、HEIC、图片、文本和 ZIP 在浏览器本地解析，库、Worker、字体和解码资源随扩展提供。不发送到在线预览、AI 或分析服务。
- 默认网站权限仅为 `https://elearning.fudan.edu.cn/*`。`webRequest` 用来识别实际文件重定向；授权按钮仅申请该目标服务器，不默认授予所有网站访问权。
- 不持久保存作业或请求日志。附件请求使用 `cache: "no-store"`，绕过浏览器已有 HTTP 缓存并避免本次响应写入 HTTP 缓存；预览仍需要传输附件并占用内存。用户主动点击下载才保存文件，本地文件选择也只在浏览器读取。
- “退出时自动清理”默认开启，设置以布尔值保存在扩展自己的 localStorage 中，不包含文件名或作业内容。退出预览、切换文件或学生会终止当前读取及解析 Worker，撤销临时 Blob 链接、清空页面和 ZIP 数据。重新开启开关会清空可复用缓存。
- 用户关闭自动清理时，远程附件可暂存在扩展 Service Worker 的内存中，以完整文件 URL、格式及所在课程／学生页面为键隔离。单文件最多 8 MiB，总量最多 24 MiB、8 个文件；最长 5 分钟，不因重复读取续期。后台休眠、浏览器退出或权限撤销也会使缓存丢失，不为缓存保持后台存活，不写入磁盘数据库。超限文件、示例和本地选择文件不缓存。每次退出仍释放渲染、解码和 ZIP 解压资源，仅保留可复用的原始附件字节。
- JavaScript 内存回收由浏览器执行。这不会删除旧 HTTP 缓存、历史记录、已下载文件，也不保证操作系统等其他层面没有残留。插件不申请全浏览器缓存清除权限。
- 不修改成绩、评语、学生列表或发布状态。可随时撤销可选网站权限或卸载扩展。
- DOCX 外部嵌入资源和 HTML 块不加载；文档网页链接仅手动点击后打开。PPT / PPTX 仅显示静态幻灯片，不加载外部图片或播放嵌入媒体。
