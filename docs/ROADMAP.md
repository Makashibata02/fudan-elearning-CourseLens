# Canvas 文件预览扩展：产品方向

用户愿景：逐步支持其他学校的 Canvas、允许选择 PDF 阅读器、支持更多文件类型，并让不熟悉计算机且不使用 VPN 的用户也能安装使用。

## 当前版本

独立 WebExtension；复旦 eLearning 是首个适配平台；PDF 是首个文件类型。学校、文件类型和阅读器在 `extension/catalog.js` 分开登记。内容脚本和后台只依赖统一文件描述，平台适配负责识别 Canvas 文件地址。构建时由学校配置生成注入范围和默认权限。

当前统一使用内置 PDF.js 阅读器，文件解析和页面显示使用打包资源，无需外部 CDN。原有用户脚本保留为兼容入口。用户已明确优先实现第 4 项愿景（免油猴、容易安装），阅读器切换等其余功能按后续迭代推进。

## 推进顺序与验收

1. **安装和分发维护。** Edge 已上架；当前维护搜索不到时的直接安装入口、中英文元数据及商店文案，并准备 Firefox 签名审核材料。已有同学反馈不开 VPN 可安装，不代表所有网络或课程文件均已验证。1.1.1 仍是本地候选，未经发布。本轮不操作商店账号、协议、签名或提交；Chrome 分发另行安排。
2. **图片与纯文本。** 分发维护完成后的下一功能阶段，先明确格式、MIME/签名检查、大小限制及错误提示。非 PDF 文件不交给 PDF 阅读器。这些功能尚未实现。
3. **更多学校。** 选择真实 Canvas 部署，验证域名、登录、文件接口及重定向，再适配有权访问的测试文件；保持最小网站权限，不能默认向所有网站注入。
4. **阅读器选择。** 更后续评估内置与浏览器原生阅读器切换及其他本地阅读器，逐项验证密码文件、批注与可访问性。不下载远程可执行插件，不默认把私有课程文件发送给在线服务。

当前不新增落地页、Office 支持或新阅读器；Markdown、音视频和校园镜像也需另行确定范围。多学校、多格式和阅读器切换均不是当前兼容性承诺。

## 架构边界

- 平台：域名许可、Canvas 链接识别、文件定位与登录要求。
- 文件：规范化后的来源 URL、文件名、格式及读取结果。
- 阅读器：只负责所支持格式的展示和用户偏好。
- 分发：浏览器清单、商店签名、离线资源、升级路径与安装帮助。

先把同学能安装、能打开文件、失败时知道怎么办验证好，再逐步扩大范围。多学校、多格式均为路线图，不是当前版本已完成的兼容性声明。
