# CourseLens 验证记录

## 2.3.0

2026-10-04 在本地构建实际扩展，41 项自动测试通过。Ubuntu 24.04 的 headless Chromium、Windows Chromium 与 Microsoft Edge 各通过 18 组模拟课程检查，包括整页阅读、滚动／手动翻页、PPT/PPTX、DOCX、HEIC、ZIP、HTTP 406、成绩及评语草稿保护，以及本次新增的检查：

- 弹窗及 SpeedGrader 内嵌预览可原地全屏／还原，覆盖按钮与 Esc 操作； iframe 阅读上下文保持不变、不重复请求附件，助教草稿不受影响。
- 安装后欢迎页以功能与示例为主，不包含版本更新、审核或发布状态。
- 默认退出后撤销临时文件链接，再打开重新请求附件。
- 关闭自动清理后复用缓存；设置跨预览保存；重新开启后清空缓存并重新请求。
- 单页图片隐藏翻页；窄窗口菜单与图片整页适应；键盘展开／关闭菜单。
- “当前页 / 总页数”作为整体在翻页控件中居中，检查不同数字长度；真实 JPEG 字节以 JIFF / JFIF 后缀从课程附件、本地文件和 ZIP 中读取，下载保持原始字节。
- 默认下载 ZIP 内所选文件，菜单可下载当前／原始文件，核对单个文件与 ZIP 整包字节；普通附件的两项均直接保存原始字节，不打开学校页面或新标签页。退出后撤销临时链接。
- 跨服务器提醒在同一页面仅主动显示一次，后续可在“更多功能”打开并取消小授权窗口。
- 展开的“更多功能”和下载菜单在预览尺寸变化后保持展开，重新定位并留在可视区域内；授权菜单也覆盖窗口尺寸变化。Ubuntu 上的已发布版本在此回归检查中失败，修复版完整通过。
- 取消授权窗口后独立验证窗口关闭、阅读器仍然可用、权限保持不变；处理 headless Chromium 在窗口自行关闭时无法返回点击确认的情形，不忽略其他点击错误。
- 缓存按学生／课程上下文隔离、大小与期限限制、权限撤销后清空，并拒绝来自网页或其他扩展的缓存操作。

本轮修复和 README 测试截图已完成本地验证。Linux 与 Edge 的授权回归复核连续通过两轮。自动检查验证了授权提醒、小窗口和取消路径；真实课程中的服务器授权确认及具体文件排版仍以实际使用结果为准，模拟检查不代替真实浏览器授权确认。每次提交的远程 CI 状态以对应工作流结果为准。
