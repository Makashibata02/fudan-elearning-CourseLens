# 无学校账号的试用

扩展菜单包含生成的两页 PDF、带表格 / 图片 / 公式的 DOCX，以及包含这些文件和文本的 ZIP。无需学校登录，可断网试用。

1. 加载 `dist/chromium/manifest.json` 所在目录，打开扩展菜单。
2. 分别打开示例 PDF / DOCX / ZIP，检查整页适应、连续 / 手动翻页、页码及缩放。
3. ZIP 顶部选择不同文件，确认预览和主动下载；普通附件可在模拟课程中验证弹窗。
4. HEIC 合成测试样例在 `tests/fixtures`，可通过本地文件入口阅读；它来自 libheif 官方样例，不是学生作业。

真实课程需要在同一浏览器登录 eLearning。内嵌阅读器遇到文件服务器授权时，可选择“独立阅读 / 授权”完成操作，再重新打开附件。不要为试用共享学生账号或私人课程文件。

浏览器自动测试的截图和结果输出到 `output/playwright/ci`，不进入 Git。它使用临时配置及模拟响应，与真实课程验收不同。
