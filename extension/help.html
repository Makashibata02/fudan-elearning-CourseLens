课程附件，直接阅读

学生可点击课程附件在当前页面弹窗阅读；助教可在 SpeedGrader 内嵌阅读并批改。

在 eLearning 的 SpeedGrader 点击文件名或“阅读作业附件”，阅读器会在左侧打开。多个附件可用下拉框切换；右侧继续使用学校原有的评分和评语功能。

支持哪些文件

  • PDF：默认适应整页和连续滚动，可选择手动翻页、页码跳转、缩放、适应宽度、文字选择、主动下载；扫描件没有文字层时只能阅读图像。
  • DOCX：连续显示分页、文字、表格、图片、页眉页脚及支持的数学公式；复杂浮动排版、图表、SmartArt、特殊公式可能与 Word 不同，批改有疑问时请下载核对。
  • PPT/PPTX：在浏览器本地解析，静态显示文字、图片及支持的图形；默认整页适应和连续滚动，也能切换手动翻页。字体、复杂图表、SmartArt、特殊公式可能与 PowerPoint 不同；动画、音视频播放和加密课件暂不支持。
  • 图片：HEIC/HEIF 苹果照片、PNG、JPEG、GIF、WebP、BMP。默认适应页面显示完整照片，支持适应宽度和缩放；HEIC 多图文件目前显示第一张照片。
  • 文本：TXT、Markdown、CSV、TSV、JSON、日志、常见代码文件和 LaTeX 源码。按纯文本显示，CSV 不作为表格计算，Markdown 和 LaTeX 不执行或排版；支持 UTF-8、带 BOM 的 UTF-16，以及 GB18030 回退。
  • ZIP：查看包内文件列表和目录路径，选择 PDF、DOCX、PPT、PPTX、HEIC、图片、文本直接阅读；其他类型可单独下载。常见 Stored/Deflate 压缩可用；加密、分卷、ZIP64 和嵌套 ZIP 预览暂不支持。
  • 旧版 DOC、DOCM、XLS/XLSX、PPTM 等暂不直接渲染，保留原下载入口。DOC 请另存为 DOCX 或 PDF。

整页与阅读方式

默认适应页面会同时按阅读区域的宽度和高度缩放，让一页或一张照片完整可见；需要看清字迹时，可选适应宽度或放大。多页 PDF/DOCX/PPT/PPTX 默认连续滚动，通过顶部阅读方式下拉框切换为手动翻页。手动模式一次显示一页，两种模式都可跳页。

学生和附件切换

阅读器打开后，附件列表更新会加载新附件。切换学生或提交版本时，旧预览会清除；没有附件时显示提示。小组共用附件或平台更新顺序特殊时，点击新学生的文件名重新打开。点击“关闭”恢复学校原有预览；其他课程页面的附件优先弹窗阅读，可点击背景或 Esc 关闭；需要时可手动选择新标签页。

如果提示授权或无法读取

先在同一浏览器登录 eLearning。默认仅能读取学校站点；文件重定向到其他服务器时，会显示需要授权的域名。内嵌阅读器中点击“独立阅读 / 授权”，在新标签页仅允许这个服务器，再回到作业页重新打开附件。无法读取时可重试或打开原文件。

本地处理与限制

PDF.js、DOCX / PowerPoint 渲染库、HEIC 解码器、ZIP 解压库和净化库随扩展安装，不从 CDN 加载代码。附件只从学校或授权的文件服务器读取，不上传到在线转换服务，不保存账号密码，不修改成绩、评语或发布状态。打开文件仍需要传输数据到浏览器；预览不会主动保存到下载目录。

单文件读取上限 100 MiB，文本预览上限 8 MiB，照片最多 5000 万像素。ZIP 最多 2048 个条目，单文件解压最多 100 MiB、声明总量最多 300 MiB，按选择解压并校验大小和 CRC。DOCX 对压缩条目和声明的解压大小做检查；异常文件可能被拒绝。密码保护的 DOCX 不支持。选择“下载文件”才会主动下载。文档里的外部链接需手动点击，外部嵌入资源和 HTML 块不加载。

安装与维护

Chrome/Edge 解压安装包，打开扩展管理页，开启开发者模式，选择“加载已解压的扩展”，选中包含 manifest.json 的文件夹。安装后刷新 eLearning 页面。更新包后在扩展管理页重新加载。请停用原同类 PDF 预览脚本或插件，避免点击处理冲突。

这是非官方开发版，与复旦大学和 eLearning 平台无官方关联。本项目的 main 为 Chrome / Edge 插件；真实课程权限、文件服务和版式仍需实际验收。

开源来源

基于 sjy0630/fudan-elearning-pdf-preview 的独立扩展分支（MIT）扩展，保留原许可证。DOCX 使用 docx-preview，PPT/PPTX 使用 @web-ppt/core，HTML 使用 DOMPurify 净化；HEIC 使用 heic-to/libheif/libde265（LGPL-3.0），ZIP 使用 fflate（MIT）；第三方许可证和 HEIC 对应源码随安装包附带。当前版本采用开发者模式安装，未发布商店版本。
